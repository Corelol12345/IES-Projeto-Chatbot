# Plataforma de Atendimento com IA - MACK INOVA Solutions

Este projeto tem como objetivo o desenvolvimento de uma **plataforma de atendimento ao cliente com Inteligência Artificial**, utilizando um **chatbot inteligente** capaz de interpretar perguntas em linguagem natural, responder com empatia e integrar-se com sistemas corporativos como CRM.

## Objetivo

Criar uma solução inovadora e acessível para automatizar atendimentos, reduzir tempo de resposta e aumentar a satisfação dos clientes da MACK INOVA Solutions, aplicando princípios de UX e técnicas modernas de IA.

---

## Funcionalidades

- Chatbot com interpretação de linguagem natural (NLP).
- Respostas empáticas e personalizadas.
- Integração com sistemas de CRM.
- Suporte a múltiplos idiomas.
- Redirecionamento para atendente humano quando necessário.
- Painel de administração e relatórios.
- Interface web acessível e responsiva.

---

## Público-Alvo

Empresas que desejam melhorar o relacionamento com seus clientes por meio de tecnologias inteligentes e eficientes de atendimento automatizado.

---


## Requisitos de Qualidade

- Tempo de resposta ≤ 2s
- Uptime mínimo de 99,5%
- Taxa de precisão das respostas ≥ 90%
- Conformidade com WCAG 2.1 (acessibilidade)
- LGPD: Armazenamento seguro de dados dos usuários

---

## Requisitos Funcionais e Não Funcionais

### Funcionais
- RF01: Iniciar conversa via interface web
- RF02: Interpretar e responder perguntas com IA
- RF03: Registrar histórico de conversas
- RF04: Redirecionar para atendente humano
- RF05: Mostrar relatórios no painel admin
- RF06: Suporte a dois idiomas
- RF07: Integração com CRM

### Não Funcionais
- RNF01: Tempo de resposta ≤ 2s
- RNF02: Layout responsivo
- RNF03: Conformidade com WCAG 2.1
- RNF04: Disponibilidade ≥ 99,5%
- RNF05: Armazenamento seguro (LGPD)

---

## Acessibilidade (WCAG 2.1)

- Contraste adequado de cores
  
    Regra: O contraste entre o texto e o fundo deve ser de pelo menos 4.5:1.
    Exemplo: Texto preto no fundo branco.
  
- Textos alternativos em imagens
  
    Regra: Todas as imagens devem ter um atributo alt.

- Navegação por teclado
  
    Regra: Todo o site deve funcionar com o teclado (tab, enter, esc, etc.).
  
- Foco visível
  
    Regra: Quando você usa TAB, o elemento selecionado (link, botão, etc.) precisa ter destaque visual.
  
- Layout responsivo
  
    Regra: O conteúdo deve se adaptar bem a diferentes tamanhos de tela (celular, tablet, desktop).

- Linguagem clara e simples

  Regra: Evitar jargões, palavras difíceis ou frases muito longas.
